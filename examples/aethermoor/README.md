# Академия Этермур

Браузерная 3D-RPG о магической академии. Мир, персонажи, сюжет и графика — оригинальные: тысячелетняя школа, четыре Круга, пятый Основатель, вычеркнутый из хроник, и Сердце Эфира под замком.

Игру можно пройти от прибытия к воротам до одной из четырёх концовок. Кнопки и системы в интерфейсе работают по-настоящему, заглушек нет.

## Быстрый старт

```bash
cd examples/aethermoor
npm install
npm run dev          # API-сервер :8790 + Vite :5173, откройте http://127.0.0.1:5173
```

Продакшен-сборка, один процесс:

```bash
npm run build        # проверка типов + сборка в dist/
npm start            # http://127.0.0.1:8790 — игра и API
```

Без сервера (например, `npm run dev:web` или статический хостинг `dist/`) игра работает полностью. Сохранения тогда хранятся только в браузере, а в интерфейсе облако помечено как «офлайн».

Переменные окружения сервера: `AETHER_PORT` (8790), `AETHER_HOST` (127.0.0.1), `AETHER_DATA` (server/data), `AETHER_DIST` (dist).

## Управление

| Действие | Клавиши |
|---|---|
| Движение / бег | WASD / Shift (в виде сверху — и стрелки) |
| Осмотреться | мышь (первый щелчок по экрану захватывает курсор, Esc отпускает), стрелки ← →, на телефоне — провести пальцем |
| Смена вида: от первого лица → из-за плеча → сверху | V |
| Кувырок (неуязвимость) | Пробел |
| Заклинание / щит | ЛКМ / ПКМ (щит в последний миг отражает снаряды) |
| Заклинания 1–6 | 1–6 |
| Взаимодействие, разговор | E |
| Быстрое зелье | Q |
| Персонаж, инвентарь, заклинания, задания, карта, отношения, дневник | C, I, K, J, M, R, L |
| Ожидание / сон | T (кровать — сон до утра) |
| Пауза, сохранение, загрузка, настройки | Esc |

На сенсорных экранах появляются виртуальный джойстик и кнопки. Все клавиши можно переназначить в настройках. Там же — чувствительность мыши, угол обзора и инверсия по вертикали.

## Что есть в игре

**Мир — 11 областей.** Врата и двор, главный этаж с Большим залом и классами, библиотека с запретной секцией, Башни Кругов со спальнями, подземелья, подземные тоннели, Шепчущий лес, деревня Ольховый Брод, Зеркальное озеро, руины Первой Академии и Затонувшее Святилище. Области открываются по сюжету. Между ними есть тайные ходы, камни быстрого перемещения и туман войны на карте.

**Сюжет в пяти актах, четыре концовки.** Прибытие и церемония Кругов. Сбои магии и запретная секция. Три печати, которые можно восстановить в любом порядке. Раскол: кто такой «П.»? Ночь Пепла и Сердце Эфира. Выборы влияют на итог: кого обвинить, пощадить ли Пеллинора, останется ли Кассиан, принять ли силу Голоса. От них зависят союзники в финале, доступные концовки и эпилог.

**Задания — 36:** 11 сюжетных, 8 побочных, 3 на отношения, 2 тайных, а также задания на бой, головоломки и исследование и 8 ежедневных поручений на доске. Они проходят в мире: цели отмечены на карте, мини-карте и над головами NPC.

**NPC — 29.** У каждого свой характер, расписание по часам и дням недели, отношения и разветвлённые диалоги с проверками характеристик, предметов, Круга и происхождения. Сюжетные события меняют расписания. Говорят 88 диалогов.

**Магия — 20 заклинаний и 5 резонансов.** Атакующие, защитные, лечебные, контроль, перемещение, а также заклинания для окружения и тайн: «Откровение» находит скрытое, «Отворение» открывает замки, «Пламя» сжигает паутину и зажигает жаровни, «Иней» замораживает воду, «Порыв» двигает блоки, «Шёпот» успокаивает духов. Резонансы: пар, огненный шторм, гром, раскол, костёр. У каждого заклинания своя стоимость, перезарядка, уровень, эффекты и звук.

**Бой в реальном времени.** 18 типов врагов с разным поведением, слабостями и наградами. 7 боссов со своими фазами и телеграфированными атаками. Кувырок, щит с отражением, статусы (горение, заморозка, оковы, оглушение) и зелья.

**Учёба.** 7 предметов с уроками по расписанию и экзаменами. Каждый урок — мини-игра: дуэль на таймингах, викторина, глифы, руническая головоломка, зельеварение, «Саймон» с существами или испытание на тренировочном поле. Ещё есть гонка на парящих дисках над озером.

**Экономика и ремесло.** 73 предмета пяти редкостей, экипировка, 4 магазина (цены зависят от репутации и происхождения), алхимия (быстрая варка или мини-игра ради качества) и артефакторика.

**Развитие героя.** Создание персонажа: имя, обращение, внешность, происхождение, Круг и характеристики. Дальше — уровни, очки характеристик, репутация пяти фракций, кубок Кругов, порча, 30 достижений и 12 скрытых знаков Основателей.

**Живой мир.** Смена дня и ночи, календарь и погода (дождь, туман, снег). Отбой и ночные патрули, случайные события, парящие свечи в Большом зале. Музыка и звуки генерируются процедурно через Web Audio, поэтому сторонних аудиофайлов нет.

**Вид от первого лица.** Игра по умолчанию идёт от первого лица: в кадре рука с жезлом, вторая рука ставит щит, прицел с мягкой доводкой на врага. Взаимодействие выбирает то, на что вы смотрите. В Большом зале — зачарованный звёздный потолок над парящими свечами. Вид из-за плеча (с отталкиванием камеры от стен) и классический вид сверху переключаются клавишей V.

**Персонажи.** Модели собираются процедурно по скелету с пропорциями по полу и возрасту. Голова вылеплена в сетке (нос, глазницы, скулы, губы, подбородок), лицо покрыто нарисованной текстурой (брови, ресницы, тени, губы, румянец, щетина, морщины у стариков, веснушки у рыжих). Глаза сидят в глазницах и моргают, губы двигаются в такт речи, NPC поворачивают голову к герою и жестикулируют в разговоре. После пробуждения NPC встают и идут по делам.

**Озвучка.** Все реплики читаются вслух через Web Speech API — голосами, установленными в системе и браузере (лучше всего звучат «Natural»-голоса Edge и голоса Google в Chrome). Каждому говорящему подобраны свой голос по полу, высота и темп; герой произносит выбранный ответ своим голосом. Текст проявляется синхронно с речью, реплики без вариантов ответа переключаются сами, NPC озвучивают и реплики мимоходом. Громкость, темп, голос героя, автопродолжение и выбор голосов — в настройках.

**Сохранения.** Автосохранение при смене области и сне, три ручные ячейки, гостевой профиль и облачная копия на сервере.

## Архитектура

```
src/
  core/        шина событий, ввод (с захватом мыши), процедурный звук, озвучка реплик (voice.ts)
  state/       zustand-хранилища: партия (сохраняется), интерфейс, настройки; формат сохранения и миграции
  data/        КОНТЕНТ: зоны (ASCII-карты + маркеры), NPC, диалоги, задания, предметы, враги, заклинания, мир
  systems/     правила: условия и эффекты (DSL), задания, диалоги, расписания, время, инвентарь, уроки, события, сохранения
  engine/      Three.js: сборка зоны, свет, камеры (сверху / из-за плеча / от первого лица), руки в кадре (viewmodel.ts),
               модели людей (humanoid.ts), игрок, NPC, враги и боссы, бой, интерактивные объекты, частицы, погода
  content/     сценарные скрипты сюжета (то, что сложнее данных)
  game/        запуск партии, новая игра / загрузка, отладочные хуки для QA
  ui/          React: экраны, HUD, гримуар (8 вкладок), диалоги, магазины, мини-игры, финал
server/        Node-сервер без зависимостей: профили, облачные сохранения, раздача dist/
scripts/       валидатор контента, сюжетный прогон, прогон интерфейса, тест API, обзор зон
```

Основные решения:

- **Контент — это данные.** Диалоги, задания, маркеры и предметы описываются через общий DSL условий (`Cond`) и эффектов (`Effect`) в `src/data/types.ts`. Чтобы добавить NPC, задание или область, движок трогать не нужно.
- **Карта — это текст.** Каждая область задаётся ASCII-сеткой с легендой и словарём маркеров (выходы, сундуки, двери, печати, враги, якоря расписаний). Движок строит из неё 3D-геометрию, коллизии, навигационную сетку и мини-карту.
- **Системы общаются через шину событий** (`core/bus.ts`): убийство, разговор, взаимодействие или флаг продвигают задания, обновляют NPC и объекты, а системы не зависят друг от друга напрямую.
- **Производительность.** Статика батчится в `InstancedMesh`. Точечных источников света 8, они распределяются между ближайшими лампами, а для остальных рисуется аддитивное свечение. Стены между камерой и героем прорезаются шейдером. Качество графики (тени, bloom, разрешение) переключается в настройках.

### Точки расширения

| Задача | Где |
|---|---|
| Новая область | `src/data/zones/<id>.ts` + регистрация в `zones/index.ts`; `npm run validate` проверит связность и ссылки |
| Новый NPC, диалог, задание | `src/data/npcs.ts`, `src/data/dialogues/*.ts`, `src/data/quests.ts` |
| Сложная сцена | `registerScript('имя', fn)` в `src/content/story.ts`, вызов эффектом `{ script: 'имя' }` |
| Другое хранилище сохранений | интерфейс `SaveRepository` в `src/systems/save.ts` |
| БД на сервере | класс `FileStore` в `server/server.mjs` (профили и сохранения) заменяется реализацией на Postgres / SQLite / KV, маршруты остаются прежними |
| Вход через аккаунт | гостевой профиль (`id` + токен, на сервере хранится только хэш токена) можно привязать к OAuth / e-mail без изменения игры |
| Музыка | `audio.ts` поддерживает манифест с файлами вместо процедурных тем |

### API сервера

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | проверка доступности |
| POST | `/api/profile` | создать гостевой профиль → `{ id, token, displayName }` |
| GET / PUT | `/api/profile` | профиль / смена имени (заголовки `x-player-id`, `x-player-token`) |
| GET | `/api/saves` | список ячеек |
| GET / PUT / DELETE | `/api/saves/:slot` | ячейки `auto`, `1`, `2`, `3`; тело `{ state, meta }` до 2 МБ |

## Проверка качества

```bash
npm run check        # типы + валидатор контента + тест API
npm run qa           # полный сюжет: акты I–V до финала через настоящие системы (нужен npm run dev)
node scripts/ui-qa.mjs   # интерфейс настоящими кликами: меню, создание героя, диалоги, гримуар, магазин, сохранения, раскладка, пробуждение NPC, телефон
node scripts/voice-qa.mjs  # озвучка: голос по полу, метки проверок не читаются, ответ героя, автопродолжение
npm run qa:tour      # снимки всех областей в qa-output/
```

- `validate-content.ts` проверяет ширину строк карт, неизвестные символы, достижимость каждого объекта от точки появления (поиск в ширину, с учётом льда), якоря расписаний, ссылки на диалоги, предметы, задания и врагов, узлы диалогов и говорящих.
- `qa.mjs` проходит кампанию: церемония, уроки (включая испытание на поле), ночной бой, сбои, запретная секция, расшифровка, лунатик с варкой зелья в котле, три печати с боссами, расследование, Ночь Пепла с волнами, дуэль, Голос, Святилище, Сорен, Полый Король, выбор и эпилог. Попутно он проверяет, что в консоли нет ошибок.

## Известные ограничения

- Персонажи и окружение строятся процедурно, без сторонних моделей и текстур: лица заметно живее примитивов, но до сканированных моделей AAA-игр им далеко.
- Качество и набор голосов зависят от системы: если русских голосов нет, реплики показываются текстом с печатной машинкой. Захват мыши может быть запрещён встроенной страницей (iframe) — тогда камера поворачивается, когда курсор у края экрана, и стрелками.
- Сюжетный прогон в CI использует отладочные хуки (`window.__aether`), например для перемещения и мгновенной победы в мини-играх. Механику боя и мини-игр проверяет отдельный прогон интерфейса.
- Облачные сохранения работают с гостевым профилем, привязанным к браузеру. Полноценной регистрации пока нет, но архитектура к ней готова (см. выше).
