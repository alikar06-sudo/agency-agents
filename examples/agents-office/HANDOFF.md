# Передача проекта в новый чат

Этот файл нужен, чтобы продолжить работу в любом другом чате, не пересказывая
всё заново. Новый чат стартует «с нуля» — он не помнит переписку, но прочитает
репозиторий. Здесь собрано то, чего в коде не видно: принятые решения, что
сделано, что осталось и где границы.

**Как продолжить:** откройте новый чат на репозитории `alikar06-sudo/agency-agents`,
**обязательно выбрав ветку `claude/feasibility-check-nj37kj`** — в `main` этой
работы нет. Затем скажите: «прочитай `examples/agents-office/HANDOFF.md` и
продолжай». Этого достаточно.

Если файл «не находится» — почти наверняка чат открыт на `main`. Проверьте:
`git branch --show-current` должно выдать `claude/feasibility-check-nj37kj`.

## Что это за проект

Панель «Agents Office» для магазина Vitaflow (Ташкент, оригинальные американские
витамины и добавки). 27 агентов в изометрическом офисе: оркестратор раздаёт
задачи, исполнитель пишет, управляющий проверяет по правилам магазина, владелец
принимает. Всё в `examples/agents-office/`.

Технически: Node.js 22, ESM, одна зависимость — `@anthropic-ai/sdk`. Остальное
стандартная библиотека. Фронтенд без сборки: три файла в `public/`.

## Что уже сделано

- **Офис и сцена.** Изометрия, 27 рабочих мест, командный центр на подиуме,
  бар с дронами-курьерами. Сотрудники печатают пальцами, пьют кофе.
- **Оркестратор** (`src/orchestrator.js`) — очередь, статусы, повторы.
- **Управляющий** (`src/review.js`) — проверяет работу по чек-листу правил
  магазина на дешёвой модели, возвращает на доработку с замечаниями.
- **Каталог** (`src/catalog.js`) — 203 позиции. В промпт идёт компактный индекс,
  полные карточки агент достаёт инструментом. Читается из файла или живьём из
  магазина по `AO_CATALOG_URL`.
- **Заказы** (`src/orders.js`) — только чтение, `AO_ORDERS_URL`.
- **Отправка покупателю** (`src/telegram.js`) — `sendMessage`, по кнопке владельца.
- **Расписание** (`src/schedule.js`) — задачи по времени, `знания/расписание.json`.
- **Встраивание в админку** — `?embed=1` плюс `AO_EMBED_ORIGIN`.
- **15 своих агентов** под Vitaflow в `agents/`, остальные 12 — из общего реестра.

Подробности по каждому — в `README.md` рядом.

## Решения, которые нельзя молча отменить

Это не предпочтения, а следствия обсуждений с владельцем. Если будете менять —
сначала спросите его.

1. **Автоотправки покупателю нет.** Агент пишет, управляющий проверяет, кнопку
   жмёт владелец. Проверка ловит нарушение правил, но не ловит «текст верный,
   но не тому человеку», а отозвать сообщение у живого человека нельзя.
2. **`getUpdates` не трогаем никогда.** У владельца работает свой бот. Второй
   читатель очереди отберёт у него апдейты и уронит приём заказов. Офис только
   отправляет.
3. **Офис ничего не пишет в магазин.** Статусы заказов меняет владелец в своей
   админке. Две системы, правящие один заказ, рано или поздно разойдутся.
4. **Себестоимость и наценка наружу не уходят.** Ни в тексты, ни в посты, ни в
   переписку. Из живого каталога они не читаются вообще.
5. **Телефоны покупателей не идут в модель.** Поле читается, но в карточку
   заказа для агента не попадает.
6. **Папка `знания/` в `.gitignore`.** Репозиторий публичный, а там реальные
   цены, себестоимость, телефон и адрес. Не добавлять в git ни при каких
   обстоятельствах.
7. **Правил возврата не существует.** Агенты не должны их выдумывать — ответ
   «уточню у менеджера», пока владелец не напишет правила.
8. **Ключи и токены не выводим** в чат, файлы, коммиты и сообщения об ошибках.

## Что ждёт владельца

Без этого агенты отвечают «уточню», и это не чинится кодом:

- ключ Anthropic и деньги на счёте (замерено: ~$0.05 за задачу с кэшем);
- правила возврата — их просто нет;
- себестоимость у 163 позиций из 203;
- бренд у 22 позиций;
- условия доставки за пределы Ташкента.

## Что предлагалось дальше

1. История покупателя — что брал раньше, на что жаловался.
2. Картинки к товарам — нужны кредиты Higgsfield.
3. Комментарии в Instagram — нужно переподключить коннектор.
4. Голосовые сообщения в боте. Владелец спрашивал про голосовой колл-центр;
   вывод был такой: телефония в Узбекистане плюс слабое распознавание узбекской
   речи делают телефон рискованным стартом, а голосовые в боте дают почти ту же
   пользу без телефонии и без требования отвечать за секунду.

## Как проверять работу

```
cd examples/agents-office
npm install
node src/server.js          # без ключа — демо-режим, модель не вызывается
```

Быстрая проверка живого сервера владельца:

```
curl -s https://agent.2-29-19-37.sslip.io/api/version?token=ТОКЕН
```

`build` — отпечаток файлов панели, `catalogSource` — откуда читается каталог.
По этому ответу видно, доехала ли выкладка и включён ли живой каталог.

Проверки репозитория перед коммитом:

```
bash scripts/check-divisions.sh && bash scripts/check-runbooks.sh \
  && bash scripts/check-tools.sh && bash scripts/lint-agents.sh \
  && bash scripts/check-agent-originality.sh
```
